## 2. Global Standards Across All Routes

### 2.1 Standard Success Envelope
All collection and single-resource responses under `/api/v1` wrap their payload in a standardized JSON envelope:
```json
{
  "data": { ... } | [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 105,
    "total_pages": 6
  },
  "meta": {
    "request_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d"
  }
}
```

### 2.2 Standard Error Envelope
All error responses (4xx, 5xx) consistently use the error envelope without exposing internal stack traces:
```json
{
  "error": {
    "code": "VALIDATION_ERROR | NOT_FOUND | UNAUTHORIZED | INTERNAL_ERROR",
    "message": "Human-readable diagnostic description",
    "request_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
    "details": [
      {
        "field": "email",
        "message": "Invalid email address format"
      }
    ]
  }
}
```

### 2.3 Required & Emitted Headers
- **`X-Request-ID`**: Set by the client or generated by `backend/src/middlewares/request-id.js` for correlation.
- **`X-Content-Type-Options: nosniff`**: Prevents MIME sniffing.
- **`X-Frame-Options: DENY`**: Prevents clickjacking framing.
- **`X-XSS-Protection: 0`**: Modern browser standard.
- **`Referrer-Policy: strict-origin-when-cross-origin`**: Limits referrer leakage.
- **`Access-Control-Allow-Origin`**: Configured via `CORS_ORIGIN` (default: `http://localhost:5173`).

## 3. Interactive Documentation (Swagger UI)

Interactive OpenAPI 3.0 documentation is served natively by the backend:
- **Swagger UI Browser URL**: [http://localhost:5001/docs](http://localhost:5001/docs)
- **Raw OpenAPI 3.0 Spec**: [http://localhost:5001/docs/openapi.json](http://localhost:5001/docs/openapi.json)

```bash
# 2. Check liveness probe
curl -s http://localhost:5001/health/live | jq .

# 3. Check readiness probe
curl -s http://localhost:5001/health/ready | jq .

# 4. View OpenAPI specification
curl -s http://localhost:5001/docs/openapi.json | jq .info
```
